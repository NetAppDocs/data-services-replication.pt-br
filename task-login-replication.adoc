= Efetue login no NetApp Replication
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Use o NetApp Console para efetuar login no NetApp Replication.

Para acessar o Console, você pode usar suas credenciais do site de suporte da NetApp ou se cadastrar para um login de NetApp cloud usando seu e-mail e uma senha. https://docs.netapp.com/us-en/console-setup-admin/task-logging-in.html["Saiba mais sobre como fazer login"^].

.Passos
. Abra um navegador da web e vá para o https://console.netapp.com/["NetApp Console"^] .
. Efetue login no Console.
. Na navegação à esquerda do Console, selecione *Proteção* > *Replicação*.
